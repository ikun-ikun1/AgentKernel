# 性能基线（2026-10-30，v0.4.0）

命令：

```bash
make bench                                  # 无 MySQL 写入
make bench DSN="$AGENTKERNEL_DB_URL"        # 含 MySQL 写入
```

本机单次采样，仅作维护期回归参考：

| 指标 | p50 | p95 | mean | n |
|---|---:|---:|---:|---:|
| CLI 启动（`python -m agentkernel --help`） | 57.83 ms | 68.07 ms | 59.63 ms | 5 |
| Agent 编排快路径（final_answer，无工具/压缩） | 0.02 ms | 0.04 ms | 0.03 ms | 20 |
| ReAct 工具轮（tool_call → calculator → 观察 → final_answer） | 0.04 ms | 0.05 ms | 0.04 ms | 20 |
| MCP knowledge_query（进程内） | 0.02 ms | 0.13 ms | 0.04 ms | 20 |
| SQLite append_message | 0.00 ms | 0.01 ms | 0.01 ms | 20 |
| MySQL append_message | 7.87 ms | 8.81 ms | 7.97 ms | 20 |

## 说明

- **Agent 编排快路径**不是“一轮 ReAct 延迟”：它只返回 final_answer，不含工具调用、上下文压缩或真实模型。
- **ReAct 工具轮**包含 tool_call → 工具执行 → 观察回灌 → final_answer，但仍使用脚本化 fake LLM，不含网络/模型时间；真实延迟以 live eval 与 JSONL `turn.latency_ms` 为准。
- MySQL 为本地回环单机，不等于线上写入能力。
- 该表是回归基线，不是 SLA；升级依赖/改核心路径后重跑并对比 p50/p95。
