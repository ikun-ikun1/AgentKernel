# 性能基线（2026-10-30，v0.4.0）

命令：

```bash
make bench                                  # 无 MySQL 写入
make bench DSN="$AGENTKERNEL_DB_URL"        # 含 MySQL 写入
```

本机单次采样，仅作维护期回归参考：

| 指标 | p50 | p95 | mean | n |
|---|---:|---:|---:|---:|
| CLI 启动（`python -m agentkernel --help`） | 58.78 ms | 61.21 ms | 58.88 ms | 5 |
| 单轮 ReAct（fake LLM，final_answer） | 0.02 ms | 0.07 ms | 0.04 ms | 20 |
| MCP knowledge_query（进程内） | 0.02 ms | 0.05 ms | 0.03 ms | 20 |
| SQLite append_message | 0.00 ms | 0.01 ms | 0.01 ms | 20 |
| MySQL append_message | 7.92 ms | 10.44 ms | 7.98 ms | 20 |

## 说明

- ReAct/MCP 不含真实模型网络时间；真实模型延迟以 live eval 与 JSONL `turn.latency_ms` 为准。
- MySQL 为本地回环单机，不等于线上写入能力。
- 该表是回归基线，不是 SLA；升级依赖/改核心路径后重跑并对比 p50/p95。
